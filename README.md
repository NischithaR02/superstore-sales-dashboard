# Superstore Sales Dashboard

## Project Overview

This project analyses retail sales performance using Power BI to identify trends, customer behaviour and business performance across categories, products and regions.

---

## Objectives

- Analyse sales and profit performance
- Investigate customer segments
- Evaluate regional performance
- Identify top-performing products
- Monitor sales trends over time

---

## Dashboard Features

- KPI Cards
  - Sales
  - Profit Margin
  - Return Rate

- Category Analysis
- Sub-Category Analysis
- State-Level Performance
- Customer Segment Analysis
- Sales Trend Analysis
- Top Products by Sales

---

## Tools & Technologies

- Power BI
- DAX
- Data Visualisation
- Business Intelligence

---

## Key Insights

- Technology generated the highest sales contribution.
- Consumer customers represented the largest customer segment.
- Sales showed an upward trend over time.
- Product and regional performance varied significantly across categories.
